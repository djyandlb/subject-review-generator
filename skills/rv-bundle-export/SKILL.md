# 合集与导出（rv-bundle-export）

## 触发条件

- 用户说「做个合集」「把几个学科放一起」「导出错题本」「打印」
- 由主编排调度（可选第 12 步）

## 输入

- 多份 `data.json`（多学科）或单个网页
- 导出目标（错题本 / 知识点清单 / 全部）

## 工作流程（多学科合集）

1. **收集**：读多份 data.json，提取各学科 subject + 章节数（= `categories.length`）+ 概念数 + 错题数
2. **生成合集首页**：一个入口 `合集.html`（输出到**用户指定目录**，默认取各学科 `index.html` 的共同父目录；多学科合集跨多个工作根 `xxx/`，不默认某个学科根），列出各学科卡片（学科名/章节数/概念数/错题数/主题预览），点击跳转到对应单文件网页
3. **保持单文件**：每个学科仍是独立单文件网页，合集只提供导航入口，不合并数据

## 工作流程（导出）

1. **错题本导出**：从目标 `index.html` 的 localStorage 读取错题（**key 按模式区分**——模板模式为 `{subject去非词字符}_wrongbook`，模块化模式为 `rv_wrong_{subject}`；最稳妥是从页面源码搜索 `STORAGE_WRONG` 常量值再读取）→ 生成清单（**data.json 无错题字段**，错题是浏览器运行时数据）
2. **知识点清单导出**：按章节导出 title + summary + content
3. **打印样式**：导出 HTML 内嵌 `@media print` 样式（去掉交互元素、优化分页）
4. **引导打印**：提示用户浏览器打印 → 另存为 PDF

## 接口契约

- 合集首页引用各学科单文件路径（相对路径）
- 导出 HTML 为自包含单文件（内联样式），可直接打印

## 阶段自检（流程末尾必做，PASS 才交付）

- **合集**：各学科入口可用（点击跳转正确，不破坏单文件独立性）
- **导出**：清单内容完整、无乱码、格式适合打印
- **FAIL → 返回修正，禁止带病交付**

## 质量要求

- 合集各学科入口可用，不破坏单文件独立性
- 导出清单内容完整、无乱码、格式适合打印

## 协作

- 依赖各学科 data.json 与单文件产物
- 可调 `slides` / `doc-writer` 辅助排版

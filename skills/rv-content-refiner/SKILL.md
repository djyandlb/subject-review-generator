# 内容结构化（rv-content-refiner）

> **定位**：详情页内容 = **考点保真 + 表达重构**——原文每一个考点原样保留（信息一条不落），表达重新组织（长句拆短、术语突出、分类归组、机制拆步）。允许改写语句，**但考点不能丢**（一段 5 个要点，输出必须仍 5 个要点，绝不压成 1 句）。
>
> **优先级**：统筹 rv-data-builder 产出的**每一张概念卡**，逐卡优化段落结构，**一张不漏**。**增强标记是优化过程中的自然副产物**——顺序铁律「先优化内容 → 再判断该加哪种标记」，禁先贴标记、禁优化与标记割裂。
>
> **通用性**：不依赖学科，靠 AI 阅读文本本身的结构信号（定义/分类/列举/特点/意义/对比），任何学科资料都适用。

## 触发条件

- 主编排调度（subject-review-generator 第 4 步之后、出题之前）——批量处理 data.json 全部概念，必做不可跳过
- 独立调用：`/rv-content-refiner` + data.json 路径 + （可选）概念 id 范围

## 输入

- `xxx/data/processed/data.json`（各概念 `content` 字段：原文段落长、术语不突出、枚举挤在一行）

## 输出

- 更新 data.json：每个概念 `content` 重写为**三段结构**——① **概念名标题段单独成段**（`<p><strong>四股螺旋DNA（Tetraplex Strands DNA）：</strong></p>`，含英文原名）② **标题与正文之间必须空行分隔**（`\n\n`，禁止标题紧贴正文）③ **正文** = `概述：`一句（引子）+ 分点分层（**主体，承载全部考点**，列表/表格/术语加粗），末尾可追加增强标记。**概念名绝不紧贴正文**
- 其余字段（id/title/subcategory/mastery/summary/tags/isKey）**不动**

## 工作流程（先优化后标记，全覆盖，每步必做 + 验收）

> **流程铁律**：统筹全部概念卡逐卡处理一张不漏；每步过「验收」。
>
> **阶段自检（绝对铁律，防带错交付）**：每步「验收」是执行时核对点（**不逐行自检烧 token**）；流程末尾做一次阶段自检——按文末「阶段自检」小节核验产物（能跑脚本的跑脚本看退出码，不能的人工抽查）；**自检全部 PASS 才交付 rv-quiz-designer**；任一项 FAIL → 返回返工，禁止带错交付。

### 第 0 步 · 统筹全部卡片（🔴必做）
**命令**：`node ./scripts/export-content.js <data.json> --out <data/temporary/refine-list.json>`｜**产物**：待优化清单（N 卡）｜**依赖**：主编排第2步
**验收**：清单条数 = data.json 概念总数（一张不漏，含已清晰的卡）｜**铁律**：禁抽样/跳过/只处理「复杂」卡

### 第 1 步 · 逐卡优化段落结构（🔴必做，主体动作）
**命令**：子 agent 固定提示词逐字必用（见「子 agent 提示词」）→ 按章分批（**每批 20-40 卡**写 `refine-part-N.json`）｜**产物**：content → 三段结构（考点保留、表达重组）｜**依赖**：第0步
**验收**：N卡→N份；每份有概述段；原文每个考点（定义/分类项/特征/数值/机制环节/鉴别点/结论）在输出中都有清晰对应｜**铁律**：逐一重构不许漏；**考点保真**——允许改写语句、精简冗余，但**禁止删考点**（多考点压成一句/丢数值/分类项/术语 = 判不合格）；勿碎片化到单卡

### 第 2 步 · 优化中识别增强标记（🔴必做，副产物）
**动作/格式要求**：对比表 `【对比表:A vs B】` / 树 `【树:标题】` / 流程 `【流程:标题】` / 速记 `【速记:标题】`｜**产物**：content 末尾追加标记（有特征才加）｜**依赖**：第1步
**验收**：标记格式过「增强标记格式规范」｜**铁律**：先优化→再判断标记，禁先贴标记；无特征不强凑

### 第 3 步 · 标记格式对齐解析器契约（🔴必做）
**动作/格式要求**：块内 `\n` 禁 `<br>`；树连字符禁箭头；速记分行问答；**树/流程/速记标题后换行**；**标记必须带标题（禁 `【树】` 无标题，须 `【树:标题】`）**｜**机器校验**：写回前跑 `node <同级skill:rv-data-builder>/scripts/check-enhance.js <data.json>`（无标题 / `<br>` 连接 / 树空格层级 = FAIL）｜**依赖**：第2步
**验收**：每条标记按「增强标记格式规范」核对（尤其 `\n`）；**check-enhance 退出码 0**｜**铁律**：标记格式是解析器渲染前提——`<br>` 连接或无标题导致标记整块不渲染（历史教训：病理学 47 处标记全不显示）

### 第 4 步 · 写回（🔴必做）
**命令**：`node ./scripts/export-content.js <data.json> --import <重构结果.json>`（**`--import` 一次只接受一个文件**——多批时先合并 `refine-part-*.json` 为一个 `refined.json`，或分多次 `--import`）｜**产物**：data.json 全部 content 更新｜**依赖**：第0-3步
**验收**：写回概念数=清单数；其余字段未动｜**铁律**：出题（主编排第5步）前完成

## 增强标记格式规范（速览/详情增强渲染的硬性格式）

> **铁律：增强标记的格式必须与模板 `parseContentEnhancements` 解析器严格一致**，否则速览聚合视图/详情增强卡不渲染。解析器在 `<同级skill:rv-builder>/scripts/patch-enhance.js` 注入的模板函数中；生成方（本工位）与解析方必须对齐同一规范。

**四种增强标记（追加在 content 末尾，用空行与正文分隔）：**

### 1. 对比表 `【对比表:A vs B vs C…】`（支持 2~N 项对比）
每行 `- 对比项 | A值 | B值 | C值…`（`|` 分隔，≥2 段；**对比对象数 = 列数**，解析器动态列渲染）：
```
【对比表:一代 vs 二代 vs 三代测序】
- 原理 | 双脱氧核苷酸终止反应 | 可逆终止边合成边测序 | 纳米孔测序
- 通量 | 低 | 高通量 | 单分子
```

### 2. 分类树 `【树:标题】`（**连字符层级，禁止 → 箭头**）
层级用行首连字符数量表示：`-`一级、`--`二级、`---`三级：
```
【树:肿瘤分类】
- 上皮组织肿瘤
-- 良性
--- 腺瘤
```

### 3. 流程链 `【流程:标题】`
步骤用 `→` 分隔（单行），或用换行+①②③：
```
【流程:大叶性肺炎四期】
充血水肿期 → 红色肝样变期 → 灰色肝样变期 → 溶解消散期
```

### 4. 速记卡 `【速记:标题】`（**必须分行问答**）
每行 `- 问题 → 答案` 或 `- 问题：答案`（`→`/`：`/`->` 分隔，≥2 段）：
```
【速记:特征性病变】
- 槟榔肝 → 慢性肝淤血，切面红黄相间如槟榔
- 心衰细胞 → 左心衰肺淤血，含铁血黄素巨噬细胞
```

**格式硬性要求：**
- 标题统一 `【标记名:标题】`（半角冒号或中文冒号均可）
- **标记块内分隔必须用真换行 `\n`，禁止 `<br>`**——解析器先剥掉 HTML 标签（`<br>` → 空格），若行间用 `<br>` 会被压成一行/单行（对比表只显首行、树层级丢失、速记全行丢弃）
- 树**禁止**用 `- 一级 → 二级` 箭头式（解析器按连字符层级读取，箭头会被当整串内容）
- 速记**禁止**单句无分隔（解析器按 `→`/`：` 切分问答，单句会被丢弃）
- **树 / 流程 / 速记标题后都必须换行**（`】\n`，否则标记块整体匹配不到；仅对比表换行可选）
- 标记块之间用空行隔开；全部标记追加在正文末尾；**每类标记一卡建议最多一个——同一卡内多个【树】/【流程】/【速记】只渲染首个（仅对比表支持多块）**
- **标记必须包含实际内容，禁止空标记**——只写「【流程:标题】」后无任何内容 = 占位空标记（AI 先写标记头忘填内容），增强卡不渲染；每条标记写完核对「标记后有实际内容」，空标记 = check-enhance FAIL
- **统一口径（逐字照抄示例，禁止自由变体）**：四类标记生成时**严格照抄上方示例格式**——对比表 `|` 行、树**连字符层级**、流程 `→`、速记**分行 `→`/`：`**；禁止变体；生成后对每条标记「套示例逐字核对」一遍，格式与示例不一致 = 不合格重写

## 子 agent 提示词（逐字必用）

调用子 agent 重构**每一张**概念卡 content 时，提示词**必须**包含以下内容（概念名与原文代入）：

> 我需要你把下面这段话做**结构化重组**：保留原文的**每一个考点**，重新组织表达让条理更清晰。产物必须是**三段结构**：① **概念名标题段单独成段**（`<p><strong>四股螺旋DNA（Tetraplex Strands DNA）：</strong></p>`，含英文原名）② **标题后必须空一行再开始正文**（禁止概念名紧贴正文）③ **正文** = `概述：`一句（引子）＋ 分点分层正文（主体，承载全部考点）。**只输出概述一句、没有正文 = 不合格；概念名紧贴正文 = 不合格**。
>
> **考点范围（一条不落）**：定义句、每个分类项/分型、每个特征/特点、每个数值、每个机制/过程环节、每个鉴别/对比点、每个结论/意义。
>
> 优化步骤：
> 1. **重组结构**：以 `<概念名> 概述：` 开篇一句话点明概念，然后正文分述——长段拆小节（加粗小标题或 `<h4>`）、枚举转列表、**关键术语加粗**、并列项归组、机制过程拆步骤。
> 2. **允许改写表达**：精简冗余啰嗦、调整语序、合并重复表述、拆分长句——**结构化本来就要改语句**，目标是让同样的考点更清楚。
> 3. **但考点一个都不能丢**：把原文每一段里**隐含的每个独立考点**都拆出来保留。**禁止**把多个考点压成一句、删掉数值/分类项/术语、一大段压成一句（那等于丢信息）。
> 4. **若原文只有一句话**（如纯定义）：概述之后也应把定义中可展开的组成/类型/要点理清呈现（只能基于原文，禁止编造）。
> 5. **完成后逐点核对**：原文有几个独立考点？输出里是否每个都还在？漏了补回。
> 6. 结构清晰后，判断是否适合添加增强标记（【对比表】A vs B 对比 / 【树】分类层级 / 【流程】步骤序列 / 【速记】特征↔表现对应）？**先看清结构再决定标记**；没有明显结构化特征就不加。
> 7. 标记按 rv-content-refiner「增强标记格式规范」追加在正文末尾（块内真换行 `\n`，树用连字符层级，速记分行问答）

## 结构化质量标准（每张卡逐一执行，不许抽查/漏）

- **逐一处理**：待优化清单 = data.json **全部概念**，每张都产出「`[概念名] 概述：`一句话 + 分点正文」**两段式**——禁止只挑部分/漏掉
- **「先总述后分述」铁律**：开篇必须 `[概念名] 概述：一句话`（点明概念），正文分点分层**呈现全部考点**——概述只是引子，正文承载考点；禁止「有概述无正文」「概述代替全文」
- **层级结构**：大主题拆成小节（加粗小标题或 `<h4>`），小节下分点；子项可三级
- **分类逻辑**：并列/同类项归组（如「按来源分」「全身 vs 局部」），每组统一结构
- **排版格式**：长句拆短句、逻辑链拆步、并列特征可转列表或表格
- **术语加粗**：每个关键术语/名词（含英文原名）必须 `<strong>` 加粗——术语不突出 = 没结构化
- **表格/口诀可选**：并列特征 ≥3 项可用 `<table>` 增强对比；核心原则可用一句加粗口诀收束（如「复位准、固定牢、早锻炼」）
- **不编造**：只重组原文，不添加资料没有的内容

### 保留重点检查清单（每张卡核对，一条不落）
- [ ] 原文**定义句** → 输出有对应（概述或分述）
- [ ] 原文每个**分类项/分型 / 特征/特点/性质 / 数值/剂量/年份 / 机制/过程环节 / 鉴别/对比点 / 结论/意义** → 输出都有
- [ ] 原文每个**考点**输出中都有对应（**数考点，不数字数**——字数可改可精简，考点不能少）
- [ ] 关键**术语已加粗**

### 反例（不合格）
- 一段话塞多个知识点不分层（「一大坨」）/ 只加 `<br>` 换行不重组逻辑（换行 ≠ 结构化）/ 简单列点无分类逻辑（散点）/ 表格堆砌无内在分类 / 先贴标记再优化（顺序错）/ 漏卡（抽查式）
- **只输出一句概述、考点没呈现**（重做）/ **多考点压成一句**（数值/分类项被合并丢弃）/ **删术语/数值/分类项**（只留主干丢考点）

### 结构化 HTML 规范（「概述 + 完整分述」完整示例）
```html
<p><strong>四股螺旋DNA（Tetraplex Strands DNA）：</strong></p>
<p>（空行）</p>
<p><strong>概述：</strong>一句话点明概念是什么（总述）</p>
<p><strong>小节标题一</strong>：</p>
<ul>
  <li><strong>分类项名</strong>：该项完整描述…（术语加粗，考点保留）</li>
</ul>
<p><strong>小节标题二</strong>：机制/特征分步…（拆步骤、保数值、术语加粗）</p>
<table>
  <tr><th>对比项</th><th>A</th><th>B</th></tr>
  <tr><td>项1</td><td>值1</td><td>值2</td></tr>
</table>
<p><strong>口诀总结</strong>：核心原则一句话…（可选）</p>
```
- 允许标签：`<p> <strong> <ul> <li> <br> <b> <h4> <table> <thead> <tbody> <tr> <th> <td>`
- **每个关键术语必须 `<strong>` 加粗**（含英文原名）；**表达可改写精简，考点保留**
- **禁止**：删改原文事实 / 添加原文没有的知识 / 把定义句压缩掉 / 只输出概述一句 / 把多个考点压成一句 / 删数值/分类项/术语
- `content` 后续由前端白名单渲染（sanitize），不含脚本/事件

## 阶段自检（流程末尾必做，PASS 才交付出题）

- **覆盖对账**：N 卡 → N 份重构结果（写回概念数 = 清单数）
- **标记格式**：`node <同级skill:rv-data-builder>/scripts/check-enhance.js <data.json>` 退出码 0
- **抽查 3 卡**：两段式（概述 + 分点正文）成立、概念名不紧贴正文、关键考点在
- **FAIL → 返回重写，禁止带病交付出题**
